# PDF Word

**Private, local PDF tools that run entirely in your browser.**

Convert between PDF and Word, merge, split, and compress PDFs — no uploads, no accounts, no tracking.

## Features

- **PDF → Word** — Extract text and download as editable `.docx`
- **Word → PDF** — Convert `.docx` / plain text into PDF
- **Merge PDFs** — Combine multiple files into one
- **Split PDF** — Extract specific pages
- **Compress PDF** — Reduce file size with object streams

All processing happens on your device.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
```

## Tech

- React 18 + TypeScript
- Vite
- Tailwind CSS
- pdf-lib
- pdf.js (pdfjs-dist)
- lucide-react

## Privacy

No PDF is ever sent to a server. There is no backend for document processing.
